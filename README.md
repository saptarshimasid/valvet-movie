# Velvet Cinema website

A responsive movie booking demo made with React, Next.js APIs, Tailwind CSS, GSAP ScrollTrigger, Locomotive Scroll, and Framer Motion. Bookings are a front-end demonstration; no payment or reservation is recorded.

## Run locally

1. Install Node.js 22.13 or newer and pnpm.
2. In this folder, run: `pnpm install`
3. Start the development server: `pnpm dev`
4. Open the localhost URL printed in the terminal.

The three original film artworks are in `public/films/`. The site UI is in `app/page.tsx` and `app/globals.css`.
